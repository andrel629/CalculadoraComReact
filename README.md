# ⚛️ Calculadora Simples em React

Este é um projeto de estudo de uma calculadora web simples, construída com React. O foco é demonstrar o uso de estado (React) para implementar a lógica básica de operações matemáticas.

## ✨ Funcionalidades

  * **Visor Dinâmico:** Os números clicados aparecem imediatamente no visor.
  * **Operações Básicas:** Suporta as quatro operações matemáticas (Soma, Subtração, Multiplicação e Divisão).
  * **Lógica de Operação:**
      * Permite inserir o primeiro número (operando A).
      * Ao clicar em um operador (ex: "+"), armazena o primeiro número e o operador.
      * Permite inserir o segundo número (operando B).
      * Ao pressionar "=" (ou outro operador para operações contínuas), exibe o resultado da operação.

## 🛠️ Tecnologias Utilizadas

  * [React](https://reactjs.org/)
  * [React Hooks](https://reactjs.org/docs/hooks-intro.html) (useState)
  * CSS (para estilização)

## 🚀 Como Executar o Projeto

Para rodar este projeto localmente, siga os passos abaixo:

1.  **Clone o repositório:**

    ```bash
    git clone https://github.com/seu-usuario/seu-repositorio.git
    ```

2.  **Navegue até o diretório do projeto:**

    ```bash
    cd nome-do-projeto
    ```

3.  **Instale as dependências:**

    ```bash
    npm install
    ```

4.  **Inicie o servidor de desenvolvimento:**
    *(O seu comando `npx start` é incomum, o padrão para projetos React é `npm start`)*

    ```bash
    npm start
    ```

O aplicativo estará disponível para visualização no seu navegador em `http://localhost:3000`.
